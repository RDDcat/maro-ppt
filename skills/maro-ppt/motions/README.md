# 모션

**모션은 슬라이드 안에서 움직이는 그래픽이다.** 도해가 관계를 *그림*으로 보여 준다면,
모션은 그 관계가 *어떤 순서로 생기는지*, 또는 *계속 돌아가고 있음*을 보여 준다.
흐름이 켜지는 순서, 숫자가 커지는 속도, 파이프라인을 계속 지나가는 패킷.

한 폴더가 한 모션이다. **여기에 폴더를 추가하면 확장 엔진이 자동으로 후보에 넣는다.**

```
motions/
├── README.md
└── kinetic-title/      ← 모션 하나
    └── motion.md       ← 필수. frontmatter + 마크업 + JS 덩이 + 쓰는 법
```

---

## 등록된 모션

| 폴더 | 이름 | 말하려는 것 | 걸리는 곳 | 반복 |
|---|---|---|---|---|
| `kinetic-title` | 제목 각인 | 이 한 문장을 기억하라 | 제목 + 리드를 감싼 `.copy` | — |
| `stagger` | 차례로 등장 | 하나씩 쌓인다 · 대화가 오간다 | `.steps` · `.trio` · `.kakao` 같은 나열 | — |
| `flow-step` | 흐름 켜기 | 이 순서로 넘어간다 | `.flow` | — |
| `count-up` | 숫자 올리기 | 이만큼 바뀌었다 | `.stat` 의 큰 숫자 | — |
| `typing` | 프롬프트 치기 | 이걸 그대로 친다 | `.prompt` | — |
| `bar-grow` | 막대 자라기 | 무엇이 얼마나 큰가 | `.bars` (모션이 CSS·마크업을 함께 준다) | — |
| `packet-flow` | 흘러가는 패킷 | 이 길로 계속 흘러간다 | `.pipe` (〃) | 패킷이 레일을 계속 지난다 |
| `cycle` | 도는 고리 | 한 바퀴로 끝나지 않는다 | `.cycle` (〃) | 표시점이 고리를 계속 돈다 |

`bar-grow` `packet-flow` `cycle` 은 스타일 카탈로그에 없는 **그래픽을 모션이 직접 가져온다** — `motion.md` 의 CSS 덩이와 마크업을 같이 붙인다.

**정해진 자리는 없다.** 어느 장에 오는지는 그 장이 하려는 말이 정한다.
`kinetic-title` 은 본문 중간의 핵심 주장에도, 마지막 장에도 걸 수 있다.

**표지에는 모션을 걸지 않는다.** 표지는 발표 전에 띄워 두는 화면이라 움직임이 볼 사람 없이 지나간다.
후킹 제목은 그대로 서 있는 게 낫다.

## 원칙 — Claude 모션에서 가져온 것

[RAISE LAB AI 모션](https://raiselab.kr/motion)에 모인 Claude 모션그래픽(HTML 한 파일 + 시간 함수)을 분석해
「강한 판」 프롬프트가 공통으로 지키는 다섯 가지를 슬라이드에 맞게 옮겼다.

| Claude 모션의 원칙 | 슬라이드에서 |
|---|---|
| **단일 콘셉트** — 모든 장면이 한 콘셉트에서 나온다 | 한 모션은 **관계 하나**만 보여 준다. 관계를 먼저 정하고 모션을 고른다. 예뻐서 고르지 않는다 |
| **서체 1종 · 색 3개 이내** | 덱의 토큰만 쓴다(`var(--ink)` `var(--lime)` `var(--paper)` `var(--line)`). 새 색·새 서체 금지 |
| **금지 목록** | 파티클 폭발 · 글로우 · 렌즈 플레어 · 흔들림 · RGB 분리 · 통통 튀는(오버슈트) 이징 · 3D 회전 · 글자 크로스페이드 · **이유 없는 반복**(아래 「반복」) |
| **박자** — 박마다 사건 하나 | 0.3~0.5초에 사건 하나. 전체 **2초 안팎**(타이핑만 최대 6초). 발표자는 말하면서 넘긴다. 길면 기다리게 된다 |
| **빌드 방법을 적는다** — `window.seek(t)`, 시간의 함수 | `draw(el, t)` — **모든 모양이 t 의 함수**다. CSS animation·transition·setTimeout 에 기대지 않는다. 그래서 `MO.seek(t)` 로 어느 순간이든 같은 장면이 나오고, Playwright 로 장을 영상으로 뽑을 수도 있다 |

슬라이드라서 더 지키는 것:

| 규칙 | 이유 |
|---|---|
| **끝 장면 = 원래 마크업** | 모션이 끝나면 정적인 슬라이드와 똑같아야 한다. 동작 줄이기·편집·발표용 저장이 전부 이 장면을 쓴다 |
| **글자는 편집 가능한 HTML 그대로** | 원래 노드는 `M.css()` 로만 모양을 바꾸고, 새 노드는 `M.gen()` 을 붙인다. SVG `<text>` 금지는 그대로 |
| **표지 제외 · 한 장에 모션 1개 · 덱 전체 4장 이하 (반복은 2장 이하)** | 다 움직이면 아무것도 안 움직이는 것과 같다. 사용자가 더 원하면 따른다 |
| **외부 요청 0건** | GSAP·Lottie·CDN 없이 인라인 JS 로 |

## 반복 — 계속 돌아가는 것만 계속 움직인다

모션은 두 가지다. **대부분은 한 번 움직이고 끝 장면에서 멈춘다.** 일부는 끝 장면 뒤로 조용한 반복이 이어진다.
반복은 "멋있으니까"가 아니라 **그 대상이 실제로 계속 돌아가고 있을 때만** 붙인다. 반복이 없는 덱이 정상이다.

| 반복이 자연스럽다 | 반복하면 안 된다 |
|---|---|
| 파이프라인을 계속 지나가는 요청·데이터 | 한 번 일어난 결과(숫자·before/after) |
| 끝이 처음으로 돌아가는 루프(만들기 → 확인 → 고치기) | 순서 설명(1 → 2 → 3) — 한 번 보면 안다 |
| 기다리는 중·돌아가는 중인 상태 | 제목·글자 — 글자는 절대 반복하지 않는다 |

반복의 규칙:

- **한 겹만.** 반복하는 건 작은 그래픽 하나(패킷·표시점)다. 상자·글자·레이아웃은 끝 장면에 고정.
- **천천히, 일정하게.** 한 주기 2~5초. 이징 없이 일정한 속도가 "계속"을 말한다. 빠르면 경고등이 된다.
- **이음매가 없다.** `loop(el, u)` 는 u 에 대해 주기 함수여야 한다. 첫 0.8초는 세기를 0→1 로 올려 끝 장면에서 스르륵 이어지게.
- **그 장에 있을 때만.** 장을 넘기면 멈춘다. 동작 줄이기·편집 중에는 반복이 없다.
- **한 장에 반복 1개, 덱 전체 2장 이하.** 반복하는 그림이 여럿이면 청중 눈이 발표자를 떠난다.
- 발표자가 끄고 싶으면 그 요소에 `data-loop="off"`.

정의에 `loop` 를 더하면 된다.

```js
MOTIONS['이름']={
  dur:1.2,
  init(el,M){…},              // 선택 — 반복용 노드는 여기서 M.gen 으로 만든다
  draw(el,t,M,dur){…},        // 0 ≤ t ≤ dur — 등장. 끝(t=dur)은 원래 마크업
  loop(el,u,M){…}             // 선택 — u = 끝 장면부터 흐른 초. 주기 함수로
};
```

## 런타임 — 템플릿에 이미 들어 있다

스타일의 `template.html` 맨 끝에 두 덩이가 있다. **둘 다 `data-editor` 가 없다** — 편집 기능을 삭제해도 모션은 남는다.

```html
<script>window.MOTIONS={};</script>   <!-- ① 모션 정의를 붙이는 곳 -->
<script>/* 모션 재생 */ … window.MO=… </script>   <!-- ② 런타임. 고치지 않는다 -->
```

| 런타임이 하는 일 | |
|---|---|
| 장에 들어오면 | 그 장의 `.mo[data-motion]` 을 0초부터 한 번 재생하고 끝 장면에서 멈춘다. `loop` 가 있으면 그 장에 있는 동안 반복이 이어진다 |
| 다시 보기 | `R`(한글 `ㄱ`) 또는 그래픽 클릭 |
| 동작 줄이기(OS 설정) | 처음부터 끝 장면, 반복 없음 |
| 편집 켜면 | 모션을 걷어 낸다(만든 노드 삭제 · 바꾼 style 복구). 원래 마크업만 고친다 |
| 저장할 때 | `MO.bare()` 가 모션 없는 마크업을 복제한다 — 파일에 애니메이션 중간 상태가 남지 않는다 |
| `MO.seek(t)` | 지금 장을 t초 장면으로 세운다. 검수·영상 추출용 |

모션 정의가 받는 도구 `M`:

| | |
|---|---|
| `M.seg(t, a, b, ease?)` | t 가 a초→b초를 지나는 동안 0→1 (기본 이징 `out`) |
| `M.css(node, {'opacity':'0', …})` | 원래 노드의 모양을 바꾼다 (kebab-case) |
| `M.gen(node)` | 새로 만든 노드에 표시를 붙인다 — 저장·편집에서 빠진다 |
| `M.lerp` `M.clamp` `M.ease.{lin,out,inOut}` | |

## 덱에 붙이는 법

1. 그 장의 감쌀 요소에 `class="mo" data-motion="{이름}"` 을 붙인다. 이미 클래스가 있으면 `mo` 를 덧붙인다.
2. `motion.md` 의 **JS 덩이**를 템플릿 ① `window.MOTIONS={};` 바로 아래에 붙인다. 같은 모션을 두 장에 써도 한 번만 붙인다.
3. 요약표에 `◆ {이름}` 으로 표시한다.

## 맞는 모션이 없으면 만든다

카탈로그는 출발점이다. **그 장이 말하려는 관계를 보여 주는 모션이 없으면 새로 만든다.**

1. 관계를 한 줄로 적는다 — "A가 B를 밀어낸다", "비용이 계단식으로 오른다".
2. 위 원칙표를 지키며 `MOTIONS['{이름}']={dur, init?, draw, loop?}` 를 쓴다. 반복은 대상이 계속 돌아갈 때만. 가장 비슷한 `motion.md` 를 베끼는 게 빠르다.
3. 덱에 붙여 `MO.seek()` 로 0초 · 중간 · 끝 장면을 확인한다. **끝 장면이 원래 마크업과 같아야 한다.**
4. 쓸 만하면 사용자에게 묻고 `motions/{이름}/motion.md` 로 등록한다. 이 README 표에 한 줄 추가.

### motion.md frontmatter

```markdown
---
motion: {폴더 이름과 같게}
label: {한국어 이름}
shows: {말하려는 관계 — 확장 엔진이 이 문장으로 매칭한다. 가장 중요하다}
when: {쓴다 / 쓰지 않는다를 가르는 한 줄}
target: {무엇을 감싸나 — 클래스 이름}
dur: {초}
loop: {없음 / 무엇이 반복되는지 한 줄}
---
```

본문에는 **언제 쓰나 · 붙이는 법(마크업) · JS 덩이 · 지켜야 할 것** 넷을 쓴다.

```
□ 모든 모양이 t 의 함수인가 (setTimeout·CSS animation 없음)
□ 끝 장면이 원래 마크업과 같은가
□ 원래 노드는 M.css 로만, 새 노드는 M.gen 을 붙였는가
□ 덱 토큰 색만 썼는가 · 금지 목록에 걸리지 않는가
□ 2초 안팎인가
□ 반복이 있다면 — 대상이 실제로 계속 돌아가는 것인가, 한 겹뿐인가, 이음매가 없는가
```
