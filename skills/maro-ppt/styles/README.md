# 스타일

한 폴더가 한 스타일이다. **여기에 폴더를 추가하면 인터뷰 선택지에 자동으로 뜬다.**

```
styles/
├── README.md
└── minimal/            ← 스타일 하나
    ├── style.md        ← 필수. 이 스타일의 규칙 (frontmatter + 본문)
    ├── template.html   ← 필수. 새 덱의 시작점
    └── design-spec.md  ← 선택. 규격 전문
```

---

## 등록된 스타일

| 폴더 | 이름 | 인상 | 어울리는 자리 |
|---|---|---|---|
| `minimal` | 최소 덱 | 아이보리 종이 바탕 · 각진 흰 카드 · 라임 형광펜 한 획 | 스터디·세미나·기술 강의 |

---

## 새 스타일 추가하는 법

**1. 폴더를 만든다.** 이름은 소문자·하이픈만. (`styles/{이름}/`)

**2. `style.md` 를 쓴다.** 맨 위 frontmatter는 인터뷰가 읽는 곳이라 형식을 지킨다.

```markdown
---
style: {폴더 이름과 같게}
label: {인터뷰 선택지에 뜰 한국어 이름}
tagline: {한 줄로 요약한 인상 — 선택지 설명이 된다}
fit: {어떤 자리에 어울리는지 한 줄}
template: template.html
---
```

본문에는 최소한 이 다섯 가지를 쓴다. `minimal/style.md` 를 베끼는 게 빠르다.

| 절 | 쓸 것 |
|---|---|
| 절대 어기지 않는 것 | 색 토큰과 깨면 안 되는 규칙 3~6개 |
| 레이아웃 | 어떤 장에 어떤 `section` 클래스를 쓰는지 |
| 도해 카탈로그 | **말하려는 관계 → 쓰는 도해** 표. 확장 엔진이 이 표에서 고른다 |
| 쓰기 규칙 | 이 스타일 고유의 문장 규칙 |
| 완료 전 체크 | 체크리스트 + grep 검증 명령 |

**3. `template.html` 을 만든다.** SKILL.md 5절의 **공통 요건**을 전부 만족해야 한다.

```
□ 외부 요청 0건 (웹폰트·CDN·http 이미지 없음) — CSS·JS 인라인, 이미지는 data URI
□ 인라인 편집 스크립트 (E 로 켜고 ⌘S 로 원본 덮어쓰기)
□ 화면 배율 스크립트 (] [ \ · --zoom 은 .slide 에만)
□ 글자가 SVG <text> 가 아니라 편집 가능한 HTML 안에 있을 것
□ 헤더 장수 자동 카운트
□ 900px·600px 에서 1단으로 접힐 것
```

`minimal/template.html` 의 `<script>` 두 덩이(편집·배율)는 스타일과 무관하다. 그대로 가져다 쓴다.

**4. 이 README 의 "등록된 스타일" 표에 한 줄 추가한다.**

---

## 확장 엔진은 스타일과 무관하다

항목을 설득 구조로 펼치는 규칙(SKILL.md 2절)은 **모든 스타일이 공유한다.**
스타일이 바꾸는 것은 *어떻게 보이는가*이지 *무엇을 몇 장으로 말하는가*가 아니다.

스타일마다 다른 것은 **도해 카탈로그** 하나뿐이다.
확장 엔진이 "순서·인과를 말해야 한다"까지 정하면,
그것을 `.flow` 로 그릴지 다른 것으로 그릴지는 그 스타일의 표가 정한다.
